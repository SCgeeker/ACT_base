# Connection Gear Template

**用途**：在 Annotation note 底部撰寫 Connection Gear，提煉卡片洞見供 Connection 使用

**使用方式**：此範本為選用指引，可自由調整或完全自由撰寫

---

## 人機協作流程（4 階段循環）

```
┌─────────────────────────────────────────────────────────┐
│  Phase 1: Card Synthesis (AI 主導)                      │
│  ─────────────────────────────────────                  │
│  AI 掃描 20 張卡片 → 提煉 5-7 候選洞見                   │
│  輸出：卡片摘要 + 候選洞見清單                           │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  Phase 2: Human Selection (人類主導)                    │
│  ─────────────────────────────────────                  │
│  審閱候選洞見 → 選擇 3-5 個 → 標記研究相關性             │
│  輸出：確認的洞見清單 + 研究方向                         │
└─────────────────────────────────────────────────────────┘
                          ↓
              ┌───────────────────────┐
              │ 可在 Phase 2-3 迭代 ↺ │
              └───────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  Phase 3: Deep Dialogue (協作)                          │
│  ─────────────────────────────────────                  │
│  AI 提問深化 ←→ 人類回答補充                             │
│  探索理論張力、識別連結、發現待解問題                    │
│  輸出：深化的洞見描述 + 連結建議                         │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  Phase 4: Gear Assembly (人類主導 + AI 審閱)            │
│  ─────────────────────────────────────                  │
│  人類撰寫 Gear 草稿 → AI 檢查完整性                      │
│  輸出：完成的 Connection Gear                            │
└─────────────────────────────────────────────────────────┘
```

### Phase 1 範例輸出

```markdown
## 卡片摘要報告 - @Barsalou-1999

### 主題叢集
- **模擬機制** (卡片 001-003, 010): 知覺符號如何運作
- **情境化概念** (卡片 004-007): 概念的情境依賴性
- **語言理解** (卡片 012-014): 模擬在語言中的角色

### 候選洞見 (5 個)
1. ⭐ 概念不是抽象符號，而是知覺經驗的再激活
2. ⭐ 模擬器 (simulator) 是表徵類型事件的神經系統
3. 概念具有高度情境變異性
4. 語言理解涉及情境模擬的建構
5. 模擬程度因概念類型而異

### 關鍵卡片標註
- 🔑 卡片 001: 核心理論主張
- 🔑 卡片 003: 模擬器定義
- 🔑 卡片 010: 具身模擬機制
```

### Phase 2 人類選擇範例

```markdown
## 我的選擇

✅ 選擇洞見 1, 2, 4（與我的心智模擬研究直接相關）
❌ 暫不選 3, 5（有趣但非當前重點）

### 研究相關性
- 洞見 1 & 2 是 [[🔗Theoretical issues]] 的理論基礎
- 洞見 4 可能連結到 [[🔗Mental Simulation of Visual Modality]]

### 補充觀點
- 我特別想探索 PSS 與 Friedrich-2025 最小主義的張力
```

### Phase 3 協作對話範例

```markdown
🤖 AI: 你選了「概念是知覺經驗的再激活」作為核心洞見。
這與 Friedrich-2025 的「最小主義具身認知」有什麼關係？
他們似乎對模擬的「強度」有不同看法。

✍️ Human: 對，Barsalou 主張所有概念都涉及模擬，
但 Friedrich 認為只有部分認知需要具身基礎。
這是一個關鍵的理論張力。

🤖 AI: 這個張力很重要。讓我建議：
- 這可以成為 [[🔗Theoretical issues]] 的框架對比表維度
- 待解問題：「何種概念類型需要強模擬 vs 弱模擬？」
- 你是否想在 Gear 中明確標注這個張力？

✍️ Human: 好主意，我會在「潛在連結」加入這個張力描述。
```

## 基本格式（選用）

```markdown
# Connection Gear

## 核心洞見
<!-- 從 20 張卡片中提煉 3-5 個最重要的洞見 -->

1. **[洞見標題]**: [簡述]
   - 來源卡片：[[cards/Author-Year-001]]、[[cards/Author-Year-005]]
   - 研究相關性：[與你的研究如何連結]

2. **[洞見標題]**: [簡述]
   - 來源卡片：[[cards/Author-Year-003]]
   - 研究相關性：[...]

## 理論框架
<!-- 本論文的主要理論立場 -->

- **框架名稱**：[理論名稱]
- **核心主張**：[一句話描述]
- **證據類型**：[實證/形式/神經/類型學]
- **與其他框架的關係**：[支持/挑戰/延伸 xxx]

## 潛在連結
<!-- 可能連結到的其他 Annotations 或 Connections -->

- 與 [[@OtherAuthor-Year]] 的 [主題] 相關
- 可能挑戰/支持 [[🔗ExistingConnection]] 的 [論點]
- **理論張力**：[與 xxx 在 yyy 議題上有分歧]

## 待解問題
<!-- 閱讀後產生的問題 -->

- [ ] [問題1]
- [ ] [問題2]
```

## 簡化格式

若不想使用結構化格式，可直接自由撰寫：

```markdown
# Connection Gear

這篇論文的核心貢獻是...

主要發現包括：
1. ...
2. ...

與我的研究相關的部分是...

可能的連結方向：...

我想進一步探索的問題：...
```

---

## 卡片引用建議

新格式 Annotation 包含 20 張原子卡片，撰寫 Gear 時可：

1. **直接引用卡片**：`[[cards/Author-Year-003|卡片標題]]`
2. **引用卡片區塊**：`[[cards/Author-Year-003#^blockid]]`
3. **摘要式引用**：「如卡片 003-007 所述...」

---

## 完成標準（自評清單）

當你能回答以下問題時，Gear 可視為完成：

- [ ] 核心洞見反映論文最重要貢獻？
- [ ] 理論框架清晰陳述？
- [ ] 至少識別 1 個潛在連結？
- [ ] 至少提出 1 個待解問題？
- [ ] 關鍵卡片有被引用？
- [ ] 與現有 Connection 的關係已標明？

完成後，更新 frontmatter：
```yaml
geared: ["🔗TargetConnection"]
```

---

## 協作啟動方式

向 Annotation Manager 說：

```
我要為 @Author-Year 撰寫 Connection Gear，
請啟動 Phase 1 卡片綜合分析。
```

或簡化版：

```
幫我分析 Barsalou-1999 的 20 張卡片，
提煉候選洞見，我要寫 Gear。
```
