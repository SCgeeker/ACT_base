# 内部隐藏状态

## 📝 核心概念 (Core Concept)
> "The RNN class has some internal state that it gets to update every time step is called... in the simplest case this state consists of a single hidden vector h."

RNN 维护一个随时间步更新的隐藏向量 h，用于保存已处理过的信息。
