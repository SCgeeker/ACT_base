# 输出置信度分配

## 📝 核心概念 (Core Concept)
> "We will then observe a sequence of output vectors, which we interpret as the confidence the RNN currently assigns to each character coming next in the sequence."

RNN 的输出向量通常被解释为对下一个可能出现的每个字符的预测得分或置信度。
