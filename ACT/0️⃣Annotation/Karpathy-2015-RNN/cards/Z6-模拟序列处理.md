# 模拟序列处理

## 📝 核心概念 (Core Concept)
> "Even if your inputs/outputs are fixed vectors, it is still possible to use this powerful formalism to process them in a sequential manner."

即使输入是静态图像（固定向量），RNN 也可以通过模拟“注意力”移动来序列化地处理这些信息。
