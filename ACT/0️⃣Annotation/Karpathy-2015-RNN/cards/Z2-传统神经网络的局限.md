# 传统神经网络的局限

## 📝 核心概念 (Core Concept)
> "A glaring limitation of Vanilla Neural Networks... is that their API is too constrained: they accept a fixed-sized vector as input... and produce a fixed-sized vector as output."

传统的全连接网络和卷积网络受限于固定的输入和输出维度，难以处理变长序列。
