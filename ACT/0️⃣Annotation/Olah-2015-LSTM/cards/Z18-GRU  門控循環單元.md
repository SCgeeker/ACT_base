# GRU  門控循環單元

## 📝 核心概念 (Core Concept)
> "GRU... combines forget and input gates into a single 'update gate.' It also merges the cell state and hidden state."

A popular LSTM variant that simplifies the architecture by combining layers and states. 
一種流行的 LSTM 變體，透過合併門控和狀態來簡化架構。
