# Recurrent Loops  循環迴路

## 📝 核心概念 (Core Concept)
> "Recurrent neural networks address this issue. They are networks with loops in them, allowing information to persist."

Loops in the architecture allow information to be passed from one step of the network to the next. 
架構中的循環迴路允許資訊從網路的一個步驟傳遞到下一個步驟。
