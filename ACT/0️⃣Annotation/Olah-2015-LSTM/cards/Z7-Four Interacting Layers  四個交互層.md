# Four Interacting Layers  四個交互層

## 📝 核心概念 (Core Concept)
> "Instead of having a single neural network layer, there are four, interacting in a very special way."

Unlike standard RNNs, the LSTM repeating module contains four neural network layers with specific interactions. 
與標準 RNN 不同，LSTM 的重複模組包含四個神經網路層，並以特殊方式交互。
