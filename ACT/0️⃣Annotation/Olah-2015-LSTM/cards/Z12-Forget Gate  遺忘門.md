# Forget Gate  遺忘門

## 📝 核心概念 (Core Concept)
> "Decide what information to throw away. It looks at $h_{t-1}$ and $x_t$."

The first step in an LSTM, deciding which information from the previous state is no longer needed. 
LSTM 的第一步，決定哪些來自前一狀態的資訊是不再需要的。
