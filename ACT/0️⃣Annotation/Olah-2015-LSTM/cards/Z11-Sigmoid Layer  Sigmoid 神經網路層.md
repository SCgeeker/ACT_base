# Sigmoid Layer  Sigmoid 神經網路層

## 📝 核心概念 (Core Concept)
> "They are composed out of a sigmoid neural net layer and a pointwise multiplication operation."

A sigmoid layer outputs numbers between 0 and 1, describing how much of each component should be let through. 
Sigmoid 層輸出 0 到 1 之間的數值，描述各個組件應該通過多少比例。
