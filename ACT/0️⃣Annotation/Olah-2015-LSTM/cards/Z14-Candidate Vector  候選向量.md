# Candidate Vector  候選向量

## 📝 核心概念 (Core Concept)
> "a tanh layer creates a vector of new candidate values... that could be added to the state."

A vector of potential new values produced by a tanh layer during the input gate stage. 
在輸入門階段由 tanh 層產生的一個潛在的新值向量。
