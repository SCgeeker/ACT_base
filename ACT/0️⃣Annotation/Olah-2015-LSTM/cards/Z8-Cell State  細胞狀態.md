# Cell State  細胞狀態

## 📝 核心概念 (Core Concept)
> "The key to LSTMs is the cell state, the horizontal line running through the top of the diagram."

This is the internal memory that carries information through the entire chain with minor linear interactions. 
這是 LSTM 的核心，作為內部記憶在整個鏈條中傳遞資訊，僅有少量的線性交互。
