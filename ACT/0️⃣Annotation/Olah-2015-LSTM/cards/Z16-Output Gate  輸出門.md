# Output Gate  輸出門

## 📝 核心概念 (Core Concept)
> "This output will be based on the cell state, but will be a filtered version."

Decides what parts of the cell state to output based on the current input and hidden state. 
根據目前的輸入與隱藏狀態，決定細胞狀態的哪些部分需要輸出。
