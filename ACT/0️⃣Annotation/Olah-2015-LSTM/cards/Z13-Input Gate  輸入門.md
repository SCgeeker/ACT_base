# Input Gate  輸入門

## 📝 核心概念 (Core Concept)
> "Decide what new information to store. A sigmoid layer decides which values to update."

Works with a tanh layer to decide which new information will be added to the cell state. 
與 tanh 層協作，決定哪些新資訊將被儲存到細胞狀態中。
